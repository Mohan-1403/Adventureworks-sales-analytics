# Power BI Analytics & Reporting Dashboard

An interactive Power BI report designed to deliver actionable business intelligence and performance insights through dynamic visualizations, comprehensive data modeling, and modern UI design.

---

## 📌 Project Overview

This repository contains the Power BI report definition, data model, and visualization configuration. The dashboard leverages clean data transformations, structured DAX calculations, and interactive visuals to allow end users to drill down into KPIs, track trends, and make data-driven decisions.

---

## 🚀 Key Features

* **Interactive Pages:** Multi-page layout covering primary business domains, detailed metrics, and executive summaries.
* **Modern UI & Theming:** Built using the standard Microsoft Fluent 2 theme for high contrast, clean typography, and readability.
* **Optimized Data Model:** Built with a star-schema-oriented architecture for fast query performance and intuitive relationship mapping.
* **DAX Measures & KPIs:** Custom time intelligence, period-over-period comparisons, and dynamic status measures.
* **Responsive Visuals:** Tailored slicers, cards, trend lines, and breakdown charts providing deep dive capabilities.

---

## 🛠️ Tech Stack & Tools

* **Business Intelligence:** Microsoft Power BI Desktop
* **Language / Calculations:** DAX (Data Analysis Expressions), Power Query (M)
* **Data Modeling:** Tabular Model, Star Schema
